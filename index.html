01 / 十条主线

从一个问题，进入整部历史。

每条主线都是一种观察方式。点选后，时间轴会显示这一主线及相关节点；你也可以组合两条主线寻找交汇处。

02 / 时间与检索

把问题放回它的时代。

目录包含已附直接来源的记录及仍在核验的候选节点。候选内容标明状态，不代表已经完成史料确认。

浏览结果

时间是为目录浏览设置的排序位置；“约”“世纪”“过程”保留原始表述。关系标签仅表示主题相关，不暗示因果。

04 / 二十条专题路径

顺着变化，继续追问。

专题是一种阅读路线，把分散的节点放回不同地区的语境。宗教与战争专题连接节点及其具体来源。

05 / 资料方法

每一条线索，
都应能回到它的依据。

网站从农业、定居社会和早期城市开始，不把一套地区分期当成全世界的统一时间表。

A

日期保留精度

世纪、约数和长期过程以原有精度展示。公元前的内部排序规则不会变成页面上的“公元 0 年”。

B

来源与状态同行

有直接来源的节点在详情页列出机构与原文链接；待核候选明确提示读者仍在编目。

C

关系逐条说明

主线标签用于检索。节点之间另列关系类型、说明和依据；时间相邻本身不代表因果。
