# 人类社会发展史图谱

本仓库根目录包含可直接部署到 GitHub Pages 的静态网站。页面使用相对路径加载 `styles.css`、`app.js` 和 `catalog.json`，适合作为 `wt1234-donkey/human-hi_story` 项目站点。

## 内容

- 十条主线、四十个节点、五条专题阅读路径。
- 三十五个节点带机构资料链接，五个节点标记为待核候选。
- 时间、地区、主题与资料状态筛选；双主线交叉阅读。

编目候选的年代、地区与关系尚需逐项核验。`catalog.json` 是当前唯一内容数据文件，修改时应保留稳定 ID 并更新来源与审核状态。专题之间的关联只是共同主题，不能自动解释为因果关系。

## 发布

将此目录中的文件直接放到仓库 `main` 分支根目录，然后在仓库的 **Settings → Pages** 中选择 **Deploy from a branch → main → /(root)**。仓库的公开性及 Pages 发布状态由 GitHub 设置决定。
