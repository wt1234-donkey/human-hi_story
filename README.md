# 人类社会发展史图谱

本仓库根目录包含可直接部署到 GitHub Pages 的静态网站。页面使用相对路径加载 `styles.css`、`app.js` 和 `catalog.json`，适合作为 `wt1234-donkey/human-hi_story` 项目站点。

## 内容

- 十条主线、二百零六个节点、三十条专题阅读路径。宗教与思想一百零七个节点，战争与安全六十七个节点。
- 二百零一个节点带资料链接，五个节点标记为待核候选。
- 宗教传统与通用子专题、时间、地区、主题与资料状态筛选；双主线交叉阅读。
- 九十七条逐条附有关系类型、解释和资料链接的节点关系，可在详情页沿关联节点继续阅读。

编目候选的年代、地区与关系尚需逐项核验。`catalog.json` 是当前唯一内容数据文件，修改时应保留稳定 ID 并更新来源与审核状态。`nodes` 条目的 `tradition`、`subtopic` 用于细分宗教目录；`relations` 以 `fromId`、`toId`、`kind`、`note`、`source` 存储有单独依据的关系。主线之间的标签关联只是共同主题，不能自动解释为因果关系。时间轴的 `year` 是浏览排序位置，年代原文以 `when` 为准。

当前主要使用博物馆、联合国教科文组织、红十字国际委员会、美国大屠杀纪念博物馆及宗教机构的公开资料。宗教机构的自述在来源名称中标明。单条来源支持概述，但更细的论断仍需逐句编注；专题导读不替代史料研究。

## 发布

将此目录中的文件直接放到仓库 `main` 分支根目录，然后在仓库的 **Settings → Pages** 中选择 **Deploy from a branch → main → /(root)**。仓库的公开性及 Pages 发布状态由 GitHub 设置决定。
